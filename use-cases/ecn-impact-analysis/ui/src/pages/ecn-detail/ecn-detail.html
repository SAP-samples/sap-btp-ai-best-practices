Checking acceptance status…

The footer prevents acceptance when the acceptance plan reports a blocker or an engineering decision is already recorded. The Blocked status column in BOM Change Evidence identifies each missing purchasing entry. Choose the material number to open its details and required action.

  • Incoming (new) parts must be listed in purchase-info-record data. Missing incoming entries block acceptance. This membership is the current surrogate for price evidence; it does not guarantee a numeric or current price.
  • Outgoing (old) material does not require price evidence for acceptance.
  • Enter your reviewer name in the decision footer, then choose Accept ECN and confirm the decision.
  • The server validates that the snapshot hash and version still match, and checks acceptance preconditions again when saving. If the snapshot changed, reload it before submitting the review.
  • The SAP update is simulated; accepting records an engineering review, not an actual SAP update.

If the acceptance plan is loading or unavailable, this is not evidence that the ECN is ready. The existing footer behavior is unchanged; the server still validates a submitted review.
